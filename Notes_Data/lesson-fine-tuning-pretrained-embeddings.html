Pre-Trained Embeddings: GloVe and FastText

As discussed in Week 2, pre-trained word embeddings offer a reusable foundation for many NLP tasks. GloVe embeddings are derived from global word co-occurrence statistics computed over massive corpora such as Wikipedia and Common Crawl. These embeddings assign each word a fixed-dimensional vector based on how often it appears near other words.

FastText improves on this approach by incorporating subword information. It represents words as combinations of character-level n-grams, allowing the model to produce embeddings even for rare or unseen words. This makes FastText particularly effective in morphologically rich languages or low-resource settings.

Both GloVe and FastText capture general semantic and syntactic information, making them well suited for transfer learning. Instead of training word vectors from scratch, models can initialize with these embeddings and reuse the linguistic knowledge encoded in them.

Why Fine-Tune?

Although pre-trained embeddings are broadly useful, they are not always optimal for every domain or task. Fine-tuning them, allowing their values to update during model training can significantly improve performance.

  • Domain shift: Pre-trained embeddings are trained on general corpora. In specialized fields such as medicine, law, or finance, fine-tuning helps the model adapt to domain-specific vocabulary and phrasing.
  • Task specificity: Sentiment analysis, named entity recognition, and text classification often benefit from embeddings that reflect the structure and priorities of the task, rather than generic similarity.
  • Improved performance: When embeddings are updated during training, they often become more effective for the problem at hand. Fine-tuned embeddings typically lead to better accuracy compared to frozen ones.

In practice, fine-tuning balances general linguistic knowledge with task-driven adaptation, especially useful when the dataset differs from the corpus used to train the original vectors.

Integrating Pre-Trained Embeddings in Deep Learning Models

Integrating pre-trained embeddings into a deep learning model involves a structured process that aligns linguistic knowledge with the model’s learning objectives. The first step is to load the pre-trained embeddings, such as GloVe or FastText, into an embedding matrix, where each row corresponds to a word in the vocabulary and contains its vector representation. This matrix encodes the semantic relationships learned during unsupervised pretraining. Next, the embedding matrix is used to initialize the model’s embedding layer, allowing the model to begin training with rich, meaningful word representations instead of random weights.

After initialization, a key design choice must be made: whether to freeze the embeddings (keeping them fixed) or fine-tune them during training. Freezing helps retain general-purpose semantics, while fine-tuning allows the vectors to adapt to the task’s specific context. Finally, the model is trained on a downstream task such as text classification, sequence labeling, or sentiment analysis. The embedding layer, whether static or trainable, serves as the input representation that guides the model’s learning process.

This integration allows deep learning models to leverage large-scale linguistic knowledge while adapting to the nuances of domain-specific or task-specific data.

Workflow of integrating pre-trained embeddings into a deep learning model.

Steps for Integrating Pre-Trained Embeddings

To leverage the benefits of pre-trained word vectors in downstream NLP models, the embeddings must be properly integrated into the training pipeline. The following steps outline the typical process used to incorporate embeddings such as GloVe or FastText into a deep learning architecture.

  1. Load pre-trained embeddings into an embedding matrix: Import pre-trained vectors (e.g., GloVe, FastText) and construct a matrix where each row corresponds to a word in the vocabulary and each column represents a feature dimension, typically ranging from 50 to 300.
  2. Initialize the model’s embedding layer with this matrix: Use the matrix to initialize the embedding layer in the neural model (e.g., RNN, CNN, or Transformer). This provides the model with semantic representations learned from large corpora.
  3. Choose whether to freeze or fine-tune the embeddings: Decide whether to keep the embeddings fixed (frozen) to retain general-purpose semantics or allow them to be updated (fine-tuned) during training to adapt to the task-specific data.
  4. Train the model on the specific task: Train the model on the target NLP task such as sentiment classification, named entity recognition, or text tagging using the initialized embeddings as input representations.

Code Example: Loading GloVe Embeddings in PyTorch

The following snippet demonstrates how to load pre-trained GloVe vectors into a PyTorch model by creating an nn.Embedding layer initialized with the embedding matrix.

import torch
import torch.nn as nn

# Assume preprocessed vocab and GloVe vectors
embedding_matrix = torch.FloatTensor(pretrained_vectors)  # shape: (vocab_size, embedding_dim)

# Create embedding layer
embedding_layer = nn.Embedding.from_pretrained(embedding_matrix, freeze=False)  # Set freeze=True to keep static/frozen

Setting freeze=False enables fine-tuning of the embedding weights during training, allowing the vectors to adapt to the task. If freeze=True, the embeddings remain static and are not updated during backpropagation—preserving their original structure.

Freezing vs Fine-Tuning

The decision to freeze or fine-tune embeddings depends on several practical factors. Below is a comparison summarizing the trade-offs involved.

Strategy Pros Cons
Frozen Faster training, avoids overfitting May underperform on domain-specific tasks
Fine-Tuned Adapts to domain, higher accuracy Slower training, risk of forgetting general semantics

Freezing is often preferred when training on smaller datasets, when prototyping rapidly, or when the target task is close to the domain of the pre-trained corpus. It minimizes training time and reduces the risk of overfitting.

In contrast, fine-tuning becomes valuable when the domain differs substantially from the original training data, or when task-specific accuracy is critical. By allowing the embeddings to adjust, the model can refine word meanings in context and achieve better generalization to specialized vocabulary and label structures.

In practice, many models begin with frozen embeddings and later enable fine-tuning once the architecture is stable and performance plateaus.

Best Practices for Fine-Tuning

Fine-tuning pre-trained embeddings can significantly improve task performance, but it must be done with care to avoid degrading useful pre-learned representations. The following practices can help guide effective tuning in real-world models:

  1. Start with lower learning rates for the embedding layer: Use a smaller learning rate for the embedding weights than for the rest of the model. This prevents abrupt updates that could erase general semantic knowledge.
  2. Monitor validation performance closely: Because fine-tuning introduces more trainable parameters, overfitting can occur, especially with limited data. Early stopping or regularization may be necessary.
  3. Use domain-specific embeddings when available: If pre-trained vectors exist for your domain (e.g., BioWordVec for biomedical text), they can offer a better starting point than general-purpose embeddings like GloVe.
  4. Apply a freeze–then–unfreeze strategy: Begin training with the embedding layer frozen, allowing other layers to stabilize. Once initial convergence is reached, unfreeze the embeddings and fine-tune them with a lower learning rate.

Thoughtful fine-tuning ensures that pre-trained embeddings are not only preserved, but adapted in ways that meaningfully improve performance on downstream tasks.

Visualizing the Effects of Fine-Tuning

In addition to performance metrics, fine-tuning can be understood through visual inspection of the embedding space. Techniques such as PCA (Principal Component Analysis) or t-SNE (t-Distributed Stochastic Neighbor Embedding) allow high-dimensional word vectors to be projected into 2D space for interpretation.

These visualizations often reveal how embeddings shift in response to task-specific training. For example, sentiment words like “good,” “great,” “bad,” and “awful” may initially appear scattered in the pre-trained space. After fine-tuning on a sentiment classification task, these words may form distinct clusters, reflecting the model’s evolving understanding of their contextual roles.

Fine-tuning doesn’t just improve classification accuracy—it reshapes the geometry of the embedding space to align with the task’s conceptual boundaries.

Code Example: Visualizing Embedding Shift with t-SNE

The following example uses t-SNE to visualize how selected word embeddings shift before and after fine-tuning.

import matplotlib.pyplot as plt
from sklearn.manifold import TSNE
import numpy as np

# Example: 8 sentiment words
words = ["good", "great", "excellent", "happy", "bad", "terrible", "awful", "sad"]

# Assume you have both pre- and post-fine-tuning embeddings
# Each should be a dictionary: word -> vector
# Shape: (num_words, embedding_dim)
embeddings_before = np.array([embedding_lookup_pre[word] for word in words])
embeddings_after = np.array([embedding_lookup_post[word] for word in words])

# Concatenate embeddings to reduce together
all_embeddings = np.vstack([embeddings_before, embeddings_after])

# Apply t-SNE to reduce dimensionality
tsne = TSNE(n_components=2, random_state=0)
reduced = tsne.fit_transform(all_embeddings)

# Split back
before_2d = reduced[:len(words)]
after_2d = reduced[len(words):]

# Plot shifts
plt.figure(figsize=(8, 6))
for i, word in enumerate(words):
    plt.scatter(*before_2d[i], color="blue", label="Before" if i == 0 else "")
    plt.scatter(*after_2d[i], color="red", label="After" if i == 0 else "")
    plt.plot(
        [before_2d[i][0], after_2d[i][0]],
        [before_2d[i][1], after_2d[i][1]],
        color="gray", linestyle="--", linewidth=0.5
    )
    plt.text(after_2d[i][0] + 0.5, after_2d[i][1], word)

plt.title("Word Embeddings Before vs. After Fine-Tuning")
plt.legend()
plt.grid(True)
plt.show()

Assumptions:

  • embedding_lookup_pre and embedding_lookup_post are Python dictionaries mapping words to their vector representations.
  • The embeddings are of the same dimensionality (e.g., 100 or 300).

Code Example: Visualizing Embedding Shifts with PCA

The following code demonstrates how to use Principal Component Analysis (PCA) to visualize how word vectors move before and after fine-tuning. This helps illustrate how embeddings adapt to the task by changing their relative positions in vector space.

import matplotlib.pyplot as plt
from sklearn.decomposition import PCA
import numpy as np

# Example: 8 sentiment words
words = ["good", "great", "excellent", "happy", "bad", "terrible", "awful", "sad"]

# Assume you have both pre- and post-fine-tuning embeddings
# Each should be a dictionary: word -> vector
embeddings_before = np.array([embedding_lookup_pre[word] for word in words])
embeddings_after = np.array([embedding_lookup_post[word] for word in words])

# Combine for joint dimensionality reduction
all_embeddings = np.vstack([embeddings_before, embeddings_after])

# Apply PCA to reduce to 2D
pca = PCA(n_components=2)
reduced = pca.fit_transform(all_embeddings)

# Split result
before_2d = reduced[:len(words)]
after_2d = reduced[len(words):]

# Plot
plt.figure(figsize=(8, 6))
for i, word in enumerate(words):
    plt.scatter(*before_2d[i], color="blue", label="Before" if i == 0 else "")
    plt.scatter(*after_2d[i], color="red", label="After" if i == 0 else "")
    plt.plot(
        [before_2d[i][0], after_2d[i][0]],
        [before_2d[i][1], after_2d[i][1]],
        color="gray", linestyle="--", linewidth=0.5
    )
    plt.text(after_2d[i][0] + 0.3, after_2d[i][1], word)

plt.title("Word Embeddings Before vs. After Fine-Tuning (PCA)")
plt.legend()
plt.grid(True)
plt.show()

When to Use PCA Over t-SNE:

  • PCA preserves linear structure and direction of shifts ideal for showing how embeddings move.
  • t-SNE preserves local neighborhoods — better for observing cluster formation but distorts global distances.

Conclusion

Fine-tuning pre-trained embeddings allows us to merge the general knowledge captured by GloVe or FastText with task-specific adjustments learned during model training. This balance often results in superior performance, especially in real-world applications like sentiment analysis or domain-specific classification.
