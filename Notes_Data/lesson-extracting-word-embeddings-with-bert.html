Lesson: Extracting Word Embeddings with BERT

Introduction

In our previous lessons, we learned that contextual embeddings from models like BERT are powerful because they change a word's vector (a list of numbers representing its meaning) based on the sentence it's in. For example, the word "bank" gets a different vector in "The bank raised interest rates" (financial institution) versus "He sat on the bank of the river" (river edge). This is a big improvement over static embeddings like Word2Vec, which give the same vector for "bank" in both cases.

In this hands-on lesson, we’ll use Hugging Face’s transformers library to extract BERT embeddings and see this context-sensitivity in action. We’ll compare how BERT represents the word "bank" in two different sentences and measure the difference using cosine similarity, a technique we discussed earlier for measuring how similar two vectors are. Let’s get started!

Learning Outcomes

By the end of this lesson, you’ll be able to:

  1. Extract contextual word embeddings using BERT from Hugging Face’s library.
  2. Identify the position of a word in a tokenized sentence using BERT’s tokenizer.
  3. Compare embeddings across different contexts using cosine similarity, and explain the difference in the embeddings of the same word in different sentence contexts.

Using Hugging Face’s Transformers Library to Generate BERT Embeddings

Generating contextual word embeddings using BERT has become a common and powerful technique in NLP pipelines. The Hugging Face Transformers library makes it easy to access and apply pretrained models like BERT with just a few lines of code. In this guide, we will walk through the essential steps to load a BERT model and generate embeddings using Python.

Step 1: Preparing the Environment for BERT Embedding Generation

Before diving into the code, we need to install the core libraries required for working with BERT: the Hugging Face Transformers library and PyTorch.

  • Transformers provides access to pretrained models like BERT, including their tokenizers and architecture.
  • PyTorch handles the underlying tensor computations and supports running models on either CPU or GPU.

These tools significantly simplify the process of loading, tokenizing, and embedding text using pretrained language models.

Installation Command

You can run the following command in your terminal or inside a Jupyter notebook:

Now that the environment is ready, let’s proceed to the next step: Load BERT’s Tokenizer and Model

Step 2: Load BERT’s Tokenizer and Model

BERT models do not process raw text directly—they operate on tokens, which are subword units generated by a tokenizer. The tokenizer converts input text into token IDs that the model understands, while the model produces contextual embeddings (vectors) for each token based on its position and surrounding context.

Here’s the code to load the tokenizer and model:

from transformers import BertTokenizer, BertModel
import torch

# Load the pre-trained BERT tokenizer and model
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")
model = BertModel.from_pretrained("bert-base-uncased", output_hidden_states=True)

Explanation

  • BertTokenizer: This splits our sentences into tokens that BERT can understand.
  • BertModel: This is the BERT model that creates the embeddings.
  • "bert-base-uncased": This is a version of BERT trained on lowercase English text, with 12 layers and 768-dimensional embeddings.
  • output_hidden_states=True: This tells BERT to give us embeddings from all 12 layers, not just the final one. We’ll use the final layer in this lesson, but this setting gives us flexibility for future experiments.

Expected Output: When you run this code, it downloads the pre-trained BERT model and tokenizer (about 440 MB if it’s your first time). You’ll see a progress bar, and then the code will finish silently, meaning the model and tokenizer are ready to use.

Step 3: Prepare Two Example Sentences

Let’s create two sentences where the word "bank" has different meanings. This will help us see how BERT adjusts its embeddings based on context.

sentences = [
    "He deposited money at the bank.",
    "They had a picnic by the bank of the river."
]

Rationale

  • In the first sentence, "bank" means a financial institution (like where you keep money).
  • In the second sentence, "bank" means the edge of a river (a physical location).
  • Since BERT creates contextual embeddings, we expect "bank" to have different vectors in these two sentences.

Let’s move on to processing these sentences with BERT!

Step 4: Tokenize the Sentences and Run Them Through BERT

Now we need to convert our sentences into a format BERT can understand (tokens and numbers) and then pass them through the BERT model to get the embeddings.

Here’s the code:

# Tokenize the sentences and convert them to a format BERT can use
inputs = tokenizer(sentences, return_tensors="pt", padding=True, truncation=True)

# Run the sentences through BERT (no gradient tracking since we're not training)
with torch.no_grad():
    outputs = model(**inputs)

Explanation

  • tokenizer(sentences, return_tensors="pt", padding=True, truncation=True):
    • return_tensors="pt": Converts the tokenized sentences into PyTorch tensors (a format BERT needs).
    • padding=True: Adds special tokens to make both sentences the same length (BERT needs this).
    • truncation=True: Cuts off sentences that are too long (not an issue here, but good practice).
  • with torch.no_grad(): Since we’re just using BERT to get embeddings (not training it), we don’t need to track gradients, which saves memory.
  • outputs = model(**inputs): This runs the tokenized sentences through BERT and gives us the embeddings.

Content of outputs

  • outputs.last_hidden_state: The embeddings from BERT’s final layer (layer 12).
  • outputs.hidden_states: The embeddings from all 12 layers (since we set output_hidden_states=True).

Output: This code runs silently (no printed output) but outputs now contains the embeddings for our sentences. We’ll extract them in the next step.

Step 5: Extract the Embeddings from BERT’s Final Layer

BERT gives us embeddings for every token in the sentence. Since we’re interested in the contextual embeddings, we’ll use the final layer (layer 12), which captures the most context.

Here’s the code:

# Get the embeddings from all layers
hidden_states = outputs.hidden_states

# Extract the final layer (layer 12)
last_layer = hidden_states[-1]

# Check the shape of the embeddings
print("Shape of last_layer:", last_layer.shape)

Explanation

  • hidden_states is a list of embeddings from all 12 layers of BERT.
  • hidden_states[-1] gives us the embeddings from the final layer (layer 12).
  • last_layer is a tensor of shape [batch_size, sequence_length, hidden_dim]:
    • batch_size: 2 (we have 2 sentences).
    • sequence_length: The number of tokens in the longest sentence (after padding).
    • hidden_dim: 768 (each token’s embedding is a 768-dimensional vector in BERT-base).

Output:

Shape of last_layer: torch.Size([2, 13, 768])

This means:

  • We have 2 sentences (batch_size = 2).
  • The longest sentence has 13 tokens (including special tokens like [CLS] and [SEP]).
  • Each token’s embedding is a 768-dimensional vector (hidden_dim = 768).

Step 6: Inspect the Tokens to Find "bank"

BERT splits sentences into tokens, and we need to find where the word "bank" appears in each sentence’s token list. Let’s convert the tokenized sentences back into readable tokens to see this.

# Convert token IDs back to readable tokens
tokens_0 = tokenizer.convert_ids_to_tokens(inputs['input_ids'][0])
tokens_1 = tokenizer.convert_ids_to_tokens(inputs['input_ids'][1])

# Print the tokens for both sentences
print("Tokens in sentence 1:", tokens_0)
print("Tokens in sentence 2:", tokens_1)

Explanation

  • inputs['input_ids']: This contains the tokenized sentences as numbers (token IDs) that BERT uses.
  • tokenizer.convert_ids_to_tokens(): This converts the token IDs back into readable tokens.
  • inputs['input_ids'][0]: The token IDs for the first sentence.
  • inputs['input_ids'][1]: The token IDs for the second sentence.

Output:

Tokens in sentence 1: ['[CLS]', 'he', 'deposited', 'money', 'at', 'the', 'bank', '.', '[SEP]', '[PAD]', '[PAD]', '[PAD]', '[PAD]']
Tokens in sentence 2: ['[CLS]', 'they', 'had', 'a', 'picnic', 'by', 'the', 'bank', 'of', 'the', 'river', '.', '[SEP]']

Rationale

  • Special Tokens:
    • [CLS]: Added at the start of every sentence (used by BERT for some tasks).
    • [SEP]: Added at the end of every sentence (marks the end).
    • [PAD]: Added to the first sentence to make it the same length as the second sentence (13 tokens).
  • Position of "bank":
    • In sentence 1 ("He deposited money at the bank."), "bank" is at index 6.
    • In sentence 2 ("They had a picnic by the bank of the river."), "bank" is at index 7.

Now that we know where "bank" is, we can extract its embeddings!

Step 7: Extract the Embeddings for "bank"

Let’s get the embeddings for the word "bank" in both sentences using the positions we found (index 6 in sentence 1, index 7 in sentence 2).

Here’s the code:

# Extract the embedding for "bank" in each sentence
embedding_bank_1 = last_layer[0][6]  # Sentence 1: "bank" (financial) at index 6
embedding_bank_2 = last_layer[1][7]  # Sentence 2: "bank" (river edge) at index 7

# Check the shape of the embeddings
print("Shape of embedding_bank_1:", embedding_bank_1.shape)
print("Shape of embedding_bank_2:", embedding_bank_2.shape)

Explanation

  • last_layer[0][6]: Gets the embedding for the token at index 6 in the first sentence ("bank" as a financial institution).
  • last_layer[1][7]: Gets the embedding for the token at index 7 in the second sentence ("bank" as a river edge).
  • Each embedding is a 768-dimensional vector that captures the meaning of "bank" in its specific context.

Output:

Shape of embedding_bank_1: torch.Size([768])
Shape of embedding_bank_2: torch.Size([768])

This confirms that each embedding is a 768-dimensional vector, as expected for BERT-base.

How BERT Embeddings Differ Across Sentence Contexts

Now that we have isolated the contextual embeddings for the word "bank" in two distinct sentences, we can examine how BERT encodes meaning based on usage. This is one of the key innovations of contextual embeddings: the same word form produces different vectors when it appears in different contexts. In the next step, we will compare these two embeddings using cosine similarity to quantify how distinct they are.

Step 8: Compare the Embeddings Using Cosine Similarity

Now we’ll compare the two embeddings for "bank" to see how similar (or different) they are. We’ll use cosine similarity, which measures how close two vectors are in space. A score of 1 means the vectors are identical, a score of 0 means they’re completely different, and a negative score means they point in opposite directions.

Here’s the code:

from torch.nn.functional import cosine_similarity

# Compute cosine similarity between the two embeddings
similarity = cosine_similarity(embedding_bank_1.unsqueeze(0), embedding_bank_2.unsqueeze(0))
print("Cosine similarity between 'bank' embeddings:", similarity.item())

Explanation

  • embedding_bank_1.unsqueeze(0): Adds an extra dimension to the embedding so cosine_similarity can process it (changes shape from [768] to [1, 768]).
  • cosine_similarity(): Calculates the cosine similarity between the two embeddings.
  • similarity.item(): Converts the result (a tensor) into a single number.

Output:

Cosine similarity between 'bank' embeddings: 0.6147

Rationale

The cosine similarity score is approximately 0.6147 (your exact number may vary slightly due to random initialization or hardware differences). This score is between 0 and 1, meaning the embeddings are somewhat similar but not identical. This makes sense because:

  • Both embeddings are for the word "bank," so they share some similarity.
  • However, the contexts are different (financial institution vs. river edge), so BERT adjusts the embeddings to reflect these different meanings.

Summary Table

To conclude this experiment, we compute the cosine similarity between the embeddings of the word "bank" in two different contexts. This allows us to quantify how BERT distinguishes between word senses while preserving some underlying semantic connection.
