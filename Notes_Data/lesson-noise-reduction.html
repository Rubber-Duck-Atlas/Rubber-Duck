Let’s get started by understanding what image filtering is all about.

Gaussian vs. Median Filtering

In image processing, noise reduction is often a necessary first step, especially before applying edge detection, segmentation, or object recognition. Two commonly used techniques for this purpose are Gaussian filtering and median filtering.

While both aim to smooth images and reduce noise, they do so in very different ways—and each has unique strengths and trade-offs. Understanding these filters' differences is essential when balancing noise suppression with image clarity and edge preservation in computer vision tasks.

What is Image Filtering?

Think of image filtering as a cleanup crew for your photos. It adjusts pixel values based on their neighbors to reduce noise, sharpen details, or emphasize important features. Random specks or graininess, known as noise, often come from camera sensors or poor lighting. Filters help smooth them out. Filtering is usually the first step in improving image quality for both a selfie touchup and preparing an image for a computer vision model.

Gaussian Filtering

Gaussian filtering is like smoothing wrinkles out of a fabric. It softens the image to reduce noise but might slightly blur sharp edges. It’s perfect for tackling Gaussian noise, those random, blurry variations in brightness you often see in photos. In computer vision, this filter is a go-to for preprocessing images before tasks like edge detection or feature extraction.

How It Works

Imagine a bell-shaped curve (a Gaussian curve) hovering over a pixel. This curve assigns weights to nearby pixels—closer ones matter more, farther ones less. The pixel’s new value is a weighted average, smoothing the image smartly.

\[ G(x, y) = \frac{1}{2\pi\sigma^2} \exp \left( -\frac{x^2 + y^2}{2\sigma^2} \right) \]

Here’s a Python example using OpenCV:

import cv2
import matplotlib.pyplot as plt

# Load a noisy grayscale image
image = cv2.imread('noisy_image.jpg', cv2.IMREAD_GRAYSCALE)

# Apply Gaussian Blur: kernel size (5,5), sigma (1) controls blur strength
gaussian_blur = cv2.GaussianBlur(image, (5, 5), 1)

# Show before and after
plt.subplot(1, 2, 1), plt.imshow(image, cmap='gray'), plt.title('Original')
plt.subplot(1, 2, 2), plt.imshow(gaussian_blur, cmap='gray'), plt.title('Gaussian')
plt.show()

Median Filtering

Median filtering is like asking a group of friends for their opinions and picking the middle one. It ignores extremes (noisy outliers) and keeps the image’s structure intact. It’s a champ at removing salt-and-pepper noise, those random black and white dots that pop up in some images. In computer vision, this filter shines when you need to preserve edges for tasks like object segmentation or contour detection.

How It Works

For each pixel, the filter looks at a small window (say, 3x3 pixels), sorts the values, and picks the median. No averaging here, just a straightforward middle value that preserves edges better than Gaussian filtering.

Here’s a code example:

# Apply Median Blur: kernel size (5) sets the window size
median_blur = cv2.medianBlur(image, 5)

# Show results with Gaussian for comparison
plt.subplot(1, 3, 1), plt.imshow(image, cmap='gray'), plt.title('Original')
plt.subplot(1, 3, 2), plt.imshow(gaussian_blur, cmap='gray'), plt.title('Gaussian')
plt.subplot(1, 3, 3), plt.imshow(median_blur, cmap='gray'), plt.title('Median')
plt.show()


Try This: Change the kernel size to 3 or 7 in the code. How does it affect the result? Think about how this might impact a computer vision algorithm detecting shapes.

Gaussian vs. Median: Which Filter Wins?

Not sure which filter to pick? Here’s a handy comparison, especially useful in computer vision:

Filter Type Best For Pros Cons
Gaussian General noise (grainy) Smooths evenly Blurs edges
Median Salt-and-pepper noise Keeps edges sharp Misses subtle noise

Use Gaussian filtering for widespread graininess (great for smoothing before feature extraction in computer vision) and median filtering when you’ve got speckles but want to keep details crisp (ideal for preserving object boundaries).

ISO Settings

Capturing high-quality images in low-light environments is a constant challenge in both photography and computer vision. One key factor that affects image quality is the ISO setting, which controls how sensitive the camera sensor is to light.

While increasing ISO helps brighten images in dark conditions, it also introduces sensor noise, or random variations that reduce detail, distort color, and interfere with computer vision tasks like object detection or edge recognition.

In this section, we’ll explore how ISO affects image quality, why noise becomes a problem in low-light settings, and which strategies can help you minimize noise while still capturing usable, vision-ready images.

What is ISO?

ISO is like your camera’s light sensitivity knob, it’s part of the exposure triangle (ISO, aperture, shutter speed). Turn it up, and your photos get brighter, but here’s the catch: higher ISO adds noise. In computer vision, managing ISO is crucial because noisy images can confuse algorithms like object detectors or classifiers.

  • Low ISO (100-200): Crisp, clean shots in bright light.
  • Medium ISO (400-800): Good for indoors, with a bit of grain.
  • High ISO (1600+): Brightens dark scenes but gets noisy.

How ISO Ties to Noise

High ISO can introduce two noise types we’ve met, both of which affect computer vision performance:

  • Gaussian Noise: Blurry grain—smooth it with Gaussian filtering.
  • Salt-and-Pepper Noise: Speckles—zap them with median filtering.

Example: Take two shots, one at ISO 100 in sunlight, one at ISO 3200 in dim light. Spot the noise difference! In computer vision, high-ISO noise might make a road sign unreadable to an autonomous vehicle.

Strategies for Low-Light Photography

Struggling with dark shots? These tips help both photographers and computer vision systems:

  1. Lower ISO when you can to cut noise (if light allows).
  2. Widen the aperture (e.g., f/2.8) to let in more light.
  3. Slow the shutter speed (use a tripod to avoid blur).
  4. Add light: Use a flashlight, phone, or apps like Softbox Pro.
  5. Post-process: Apply filters in software like Lightroom or OpenCV to prep images for vision tasks.

Here’s an ISO cheat sheet:

ISO Range Light Conditions Noise Level Best Use
100-200 Bright Low Sunny days
400-800 Indoor Moderate Overcast/indoor
1600+ Low light High Night shots
