Lesson: Adding Attention to Seq2Seq Models

Introduction

In the previous lessons, we implemented a basic Sequence-to-Sequence (Seq2Seq) model using TensorFlow and Keras to translate English phrases to French. We identified its limitation: the fixed-length bottleneck, where the encoder compresses all input information into a single context vector. This can hinder performance for longer sequences.

In this lesson, you will enhance the Seq2Seq model by adding an attention mechanism, which allows the decoder to focus on relevant parts of the input sequence dynamically. You will modify the existing model, implement the attention layer, train the updated model, and visualize attention weights to understand how the model prioritizes input tokens during translation.

Learning Outcomes

By the end of this lesson, you will be able to:

  1. Implement an attention mechanism in a Seq2Seq model using TensorFlow/Keras.
  2. Train the attention-enhanced model for English-to-French translation.
  3. Visualize attention weights to interpret the model's focus during translation.

Enhancing the Seq2Seq Model with Attention

The traditional Seq2Seq architecture relies on compressing the entire input sequence into a single fixed-length vector—an approach that often degrades in quality for long or complex sequences. To overcome this limitation, we incorporate an attention mechanism into the Seq2Seq model. Attention allows the decoder to dynamically focus on relevant parts of the input sequence at each time step, rather than depending solely on the encoder's final state. This enhancement leads to significantly better performance in tasks such as translation, summarization, and question answering. In this section, we begin by preparing a small English–French parallel corpus tailored for training a Seq2Seq model with attention. Subsequent sections will build on this foundation by integrating attention into the model architecture.

To implement attention in a Seq2Seq framework, we begin by revisiting the model architecture. In the next step, we will construct the attention-enhanced Seq2Seq model by modifying the encoder to return full hidden states and integrating an attention layer into the decoder pipeline.

Step 1: Building the Attention-Enhanced Model

To improve upon the classical Seq2Seq model's limitations, particularly its inability to dynamically focus on relevant parts of the input—we now integrate an attention mechanism into the architecture. Specifically, we employ a Bahdanau-style attention layer, which allows the decoder to attend selectively to all encoder outputs at each time step. This enhancement leads to better performance on longer or structurally complex sequences by enabling the model to learn soft alignments between source and target tokens.

Model Parameters and Vocabulary Setup

Before defining the model architecture, we initialize important parameters and determine vocabulary sizes for both source and target languages.

from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, LSTM, Embedding, Dense, Attention

# Latent dimensionality for embeddings and LSTM units
latent_dim = 64

# Vocabulary sizes (input and output)
vocab_in_size = len(input_tokenizer.word_index) + 1
vocab_out_size = len(target_tokenizer.word_index) + 1

Encoder Definition

The encoder processes the input sequence and returns:

  • The sequence of all hidden states (needed for attention)
  • The final hidden and cell states (used to initialize the decoder)
# Encoder definition
encoder_inputs = Input(shape=(None,))
enc_emb = Embedding(input_dim=vocab_in_size, output_dim=latent_dim)(encoder_inputs)

# LSTM returns sequences and final states
encoder_outputs, state_h, state_c = LSTM(
    latent_dim, return_sequences=True, return_state=True
)(enc_emb)

# Store the final encoder states for initializing the decoder
encoder_states = [state_h, state_c]

Decoder Definition with Attention

The decoder generates the output sequence while attending to relevant parts of the input via the attention mechanism.

# Decoder input layer
decoder_inputs = Input(shape=(None,))
dec_emb_layer = Embedding(input_dim=vocab_out_size, output_dim=latent_dim)
dec_emb = dec_emb_layer(decoder_inputs)

# Decoder LSTM uses the encoder's final states as initial state
decoder_lstm = LSTM(latent_dim, return_sequences=True, return_state=True)
decoder_outputs, _, _ = decoder_lstm(dec_emb, initial_state=encoder_states)

# Attention mechanism: aligns decoder output with encoder output
attention = Attention()
attention_output = attention([decoder_outputs, encoder_outputs])

# Here we simplify by using attention output directly
decoder_concat = attention_output

# Final output layer: predicts vocabulary token probabilities
decoder_dense = Dense(vocab_out_size, activation='softmax')
decoder_outputs = decoder_dense(decoder_concat)

Attention Integration

We now align the decoder outputs with the encoder's full sequence of hidden states using a Bahdanau-style attention mechanism.

# Attention layer computes alignment between decoder outputs and encoder outputs
attention = Attention()

# Output: contextually weighted representation of encoder outputs
attention_output = attention([decoder_outputs, encoder_outputs])

Note: The Attention layer used here computes dot-product attention, which behaves similarly to Bahdanau-style when integrated with LSTM output sequences.

Concatenation and Output Prediction

Here, we simplify by passing the attention-weighted outputs directly into the final dense layer, which predicts the next token at each timestep.

# Use attention output directly for prediction
decoder_concat = attention_output

# Output layer: predicts vocabulary token probabilities
decoder_dense = Dense(vocab_out_size, activation='softmax')
decoder_outputs = decoder_dense(decoder_concat)

Summary

  • The encoder now outputs all hidden states to support attention.
  • The decoder attends to all encoder outputs at each decoding step, improving alignment between source and target.
  • The attention-enhanced model allows more accurate and context-sensitive sequence generation.

This completes the architecture definition. In the next step, we will compile and train the attention-augmented model using the prepared dataset.

Step 2: Compiling and Training the Attention-Enhanced Seq2Seq Model

With the architecture of the attention-augmented Seq2Seq model defined, the next step is to compile and train it. This involves specifying the optimization strategy and loss function, followed by fitting the model to the preprocessed data. Given that the target outputs are sequences of integer-encoded tokens (not one-hot vectors), we use sparse_categorical_crossentropy as the appropriate loss function.

Model Compilation

We assemble the model using Keras' functional API and specify the following training configurations:

  • Optimizer: Adam—commonly used for sequence models due to its adaptive learning rate.
  • Loss Function: sparse_categorical_crossentropy—handles integer-encoded targets efficiently.
  • Metric: accuracy—monitors the proportion of correctly predicted tokens during training.
# Assemble the full model
model = Model([encoder_inputs, decoder_inputs], decoder_outputs)

# Compile the model
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

Model Training

We now train the model using the input and target sequences prepared earlier. The decoder_target_data is expanded in its last dimension to match the expected shape of (samples, timesteps, 1) required for sparse loss computation.

Step 3: Inference with Attention

Once the attention-augmented Seq2Seq model has been trained, we need to prepare it for inference, the process of generating translations one token at a time. Unlike training, where the entire target sequence is known and fed to the decoder via teacher forcing, inference must proceed step-by-step, using only the previously generated token and the model’s internal state at each decoding step. To support this, we split the model into two components:

  • Encoder Model for Inference: Encodes the input and returns hidden states and full encoder outputs (for attention).
  • Decoder Model for Inference: Takes the previous token, decoder states, and encoder outputs, and returns the next token prediction along with updated states and attention context.

Constructing the Inference Models

To perform inference using the trained attention-based Seq2Seq model, we must construct separate models for the encoder and decoder. These inference models operate differently from the training model: instead of processing entire sequences at once, they generate the output token-by-token, maintaining and updating internal states at each step. This structure enables dynamic decoding and allows attention to guide the generation process.

Encoder Inference Model

The encoder inference model is responsible for processing the entire input sequence and producing two outputs: (1) the full sequence of hidden states, which will be used by the attention mechanism, and (2) the final hidden and cell states, which initialize the decoder. This model is identical to the encoder used during training, except that its outputs are now exposed for use in the decoding process.

# Encoder inference model: outputs encoder hidden states and final LSTM states
encoder_model = Model(encoder_inputs, [encoder_outputs, state_h, state_c])

Decoder Inference Model with Attention

Unlike training, where the decoder receives the entire target sequence at once, inference requires the decoder to generate the output sequence one token at a time. The decoder inference model is designed to handle this step-by-step process. It takes the previous token, the encoder's output sequence (for attention), and the decoder’s previous hidden states to predict the next token. It also returns updated states for use in subsequent decoding steps. We define a decoder model that:

  • Accepts one input token at a time.
  • Uses encoder outputs for attention.
  • Maintains decoder LSTM states across steps.
from tensorflow.keras.layers import Input

# Inputs for decoder state and encoder outputs during inference
decoder_state_input_h = Input(shape=(latent_dim,))
decoder_state_input_c = Input(shape=(latent_dim,))
decoder_states_inputs = [decoder_state_input_h, decoder_state_input_c]
encoder_outputs_input_decoder = Input(shape=(None, latent_dim))  # All encoder hidden states

# Decoder receives one token at a time
decoder_inputs_single = Input(shape=(1,))  # Shape: (batch_size=1, timestep=1)

# Reuse decoder embedding layer
dec_emb2 = dec_emb_layer(decoder_inputs_single)

# LSTM step with prior states
decoder_outputs2, state_h2, state_c2 = decoder_lstm(dec_emb2, initial_state=decoder_states_inputs)

# Attention mechanism: aligns decoder output with encoder outputs
attention_layer = Attention()
attention_output2 = attention_layer([decoder_outputs2, encoder_outputs_input_decoder])

# Prediction via dense layer over attention output
decoder_outputs2 = decoder_dense(attention_output2)

# Final decoder inference model
decoder_model = Model(
    [decoder_inputs_single, encoder_outputs_input_decoder] + decoder_states_inputs,
    [decoder_outputs2, attention_output2, state_h2, state_c2]
)

Integrating the Attention Mechanism

At each decoding step, the attention mechanism dynamically computes a context vector by aligning the current decoder state with all encoder hidden states. This context vector helps the decoder focus on the most relevant parts of the input sequence when generating the next token. By integrating attention into the decoder inference model, we enable more accurate and context-aware translation output.

Translation Function with Attention Tracking

This function generates output token-by-token, recording attention weights at each step for possible visualization.

def decode_sequence_with_attention(input_seq):
    # Encode the input and initialize decoder states
    encoder_outs, state_h, state_c = encoder_model.predict(input_seq)
    states_value = [state_h, state_c]

    # Start the target sequence with <sos>
    target_seq = np.array([[target_tokenizer.word_index['<sos>']]])

    decoded_sentence = []
    attention_weights_list = []
    stop_condition = False

    while not stop_condition:
        # Predict next token
        output_tokens, attention_output, h, c = decoder_model.predict(
            [target_seq, encoder_outs] + states_value
        )

        # Get the highest probability token
        sampled_token_index = np.argmax(output_tokens[0, -1, :])
        sampled_word = target_tokenizer.index_word.get(sampled_token_index, '[UNKNOWN]')

        # Check for end-of-sequence or length limit
        if sampled_word == '<eos>' or len(decoded_sentence) > max_target_len:
            stop_condition = True
        else:
            decoded_sentence.append(sampled_word)
            attention_weights_list.append(attention_output[0])  # Shape: (1, max_input_len)

        # Prepare next decoder input and update states
        target_seq = np.array([[sampled_token_index]])
        states_value = [h, c]

    return ' '.join(decoded_sentence), attention_weights_list

Summary

  • The inference process uses separate encoder and decoder models.
  • Attention allows the decoder to focus on different parts of the input dynamically.
  • The model now generates translations step-by-step, enabling visualization and interpretability via attention weights.

Step 4: Visualizing Attention Weights

One of the key benefits of integrating attention into a Seq2Seq model is its interpretability. Attention mechanisms allow us to see which input tokens the model focuses on while generating each word in the output sequence. To make this behavior more tangible, we can visualize the attention weights as a heatmap, which displays how much "attention" the decoder pays to each input token at every step of translation. This visualization helps to:

  • Interpret the translation process.
  • Diagnose translation errors or mismatches.
  • Gain insights into model behavior, especially in educational or debugging contexts.

Implementing Attention Visualization

We define a function to display the attention weights using Matplotlib and Seaborn:

import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np

Heatmap Function Definition

def plot_attention_weights(attention_weights, input_text, decoded_sentence):
    # Skip if data is missing
    if not attention_weights or not decoded_sentence:
        print("No attention weights or empty translation; skipping visualization.")
        return

    # Tokenize input and output
    input_tokens = input_text.split()
    output_tokens = decoded_sentence.split()

    # Convert attention list to NumPy array and remove redundant dimensions
    attn_matrix = np.squeeze(np.array(attention_weights), axis=1)

    # Crop matrix to actual number of tokens
    attn_matrix = attn_matrix[:len(output_tokens), :len(input_tokens)]

    # Create heatmap
    plt.figure(figsize=(max(8, len(input_tokens)), max(6, len(output_tokens))))
    sns.heatmap(attn_matrix, 
                xticklabels=input_tokens, 
                yticklabels=output_tokens, 
                cmap='Blues', 
                vmin=0, vmax=1)

    plt.xlabel('Input Tokens')
    plt.ylabel('Output Tokens')
    plt.title('Attention Weights Heatmap')
    plt.show()

Testing the Visualization

Step 5: BLEU Score Evaluation

To evaluate the performance of our attention-enhanced Seq2Seq model, we apply the BLEU (Bilingual Evaluation Understudy) metric. BLEU is a widely used method for assessing machine translation quality by comparing model-generated translations (hypotheses) with one or more correct reference translations. It operates by measuring n-gram overlap between the hypothesis and reference. Although our model is trained on a small dataset, BLEU can still provide a useful indication of how well the model has learned basic translation mappings.

BLEU Evaluation Procedure

We use sentence-level BLEU scores from the nltk.translate.bleu_score module. Each hypothesis is evaluated against its corresponding reference.

from nltk.translate.bleu_score import sentence_bleu

Define Test Data

# Ground-truth reference translations (tokenized)
references = [['merci'], ['comment ça va']]

# Corresponding source sentences (English)
tests = ['thank you', 'how are you']

Evaluate Predictions

# Evaluate each test input against its reference
for sentence, ref in zip(tests, references):
    # Preprocess the input sentence
    seq = input_tokenizer.texts_to_sequences([sentence])
    seq = pad_sequences(seq, maxlen=max_input_len, padding='post')

    # Run inference using the attention-enabled decoder
    hyp, _ = decode_sequence_with_attention(seq)

    # Output results
    print(f"Input: {sentence}")
    print(f"Hypothesis: {hyp}")
    print("BLEU:", sentence_bleu([ref], hyp.split()))
