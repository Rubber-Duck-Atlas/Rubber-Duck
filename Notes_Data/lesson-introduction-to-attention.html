Lesson: Introduction to Attention

Introduction

In our previous lessons, we explored the encoder-decoder structure of Sequence-to-Sequence (Seq2Seq) models and implemented one using LSTMs. While this architecture performs well on short sequences, its effectiveness degrades as sequence length increases due to its reliance on a fixed-size context vector. This creates an information bottleneck, preventing the decoder from accessing relevant parts of the input at the right time.

In many deep learning tasks, especially involving sequential or structured data, it is crucial for the model to weigh the relevance of different elements in an input. To solve this problem, the attention mechanism was introduced, it enables this capability. Instead of processing inputs in a fixed order (as in RNNs), attention allows the model to learn dynamic weighting of inputs based on their contextual importance.

In this lesson, we will dissect the self-attention mechanism, understand the role of Query (Q), Key (K), and Value (V) matrices, and explore how multi-head attention enriches representational power. We will also contrast attention with fixed-context models and briefly mention applications in other domains like computer vision and reinforcement learning.

  2. Describe the core mechanism of additive attention (Bahdanau).
  3. Differentiate between self-attention and encoder-decoder attention.
  4. Interpret multi-head attention as used in Transformer-based models.

Motivation Behind Attention

While the classical Sequence-to-Sequence (Seq2Seq) architecture offers a foundational framework for tasks like machine translation and text summarization, it suffers from critical limitations, particularly when handling long or information-rich sequences. These shortcomings arise from how the model represents input context during decoding.

The Limitation: Fixed-Length Encoding

In a traditional Seq2Seq model, the entire input sequence is compressed into a single, fixed-length context vector, which is typically the final hidden state of the encoder. This vector is expected to encapsulate all semantic and syntactic information needed to generate the output sequence.

However, this design presents major issues:

  • Information Bottleneck: All details from the input, regardless of sequence length, must be squeezed into one vector. As input complexity increases, the capacity of this vector becomes insufficient.
  • Poor Long-Sequence Performance: For longer or more complex sentences, the decoder often lacks access to relevant portions of the input, leading to degraded output quality.
  • No Direct Access to Tokens: The decoder has no mechanism to selectively revisit specific parts of the input sequence. It must rely entirely on what the final encoder state retained.

Analogy: Asking a student to summarize an entire textbook after reading it once and recalling only the last sentence.

The bottleneck problem.

The Solution: Dynamic Focus with Attention

To address this bottleneck, researchers introduced attention mechanisms, which fundamentally change how context is handled in the decoder. Instead of relying on a single static vector, attention allows the decoder to:

  • Access all encoder hidden states, not just the final one.
  • Dynamically focus on different parts of the input sequence at each decoding step.
  • Learn which input words are most relevant to generating the current output token.

This approach enhances model performance, particularly on longer sequences, by allowing more flexible and context-aware decoding.

Attention Mechanism

Attention solves this by giving the decoder direct access to all encoder hidden states. At each decoding step, the decoder computes a context vector \(C_i\) as a weighted average of all encoder outputs. These weights—called attention scores reflect the importance of each input token for generating the current output token. With this, we finally have a fixed-length context vector that takes into account information from the entire encoder state that is dynamically updated to reflect the needs of the decoder at each step of decoding. the next figure illustrates an encoder-decoder network with attention, focusing on the computation of one context vector \(C_i\)

It is computed by taking the weighted sum of all the encoder hidden states, each weighted by their dot product with the prior decoder hidden state \({h_{i-1}}^d\)

Understanding Self-Attention

While traditional attention mechanisms in Sequence-to-Sequence (Seq2Seq) models operate between the encoder and the decoder allowing the decoder to selectively attend to parts of the encoder’s output, self-attention shifts the focus inward. It enables a model to capture dependencies within a single sequence, allowing each token to consider the context provided by every other token in that sequence. This internal relational capability is foundational to the Transformer architecture, which replaces recurrence and convolution entirely with parallelizable self-attention mechanisms.

Role of Self-Attention

Self-attention addresses several key limitations of earlier models like RNNs:

  • Long-Range Dependency Modeling: Unlike RNNs, which struggle with distant relationships due to vanishing gradients, self-attention captures long-range dependencies in a single computation step.
  • Parallelization: All tokens in the sequence are processed simultaneously, enabling substantial speed-ups during both training and inference.
  • Dynamic Contextualization: Each token in the input sequence is represented not only by its identity but also by its relation to all other tokens—yielding more informative and flexible representations.

How Self-Attention Works

At its core, self-attention allows each input token to compute a weighted representation of the entire sequence, including itself. The mechanism learns to assign higher attention weights to tokens that are more relevant in a given context.

For example, consider the sentence:

"The chicken didn’t cross the road because it was too tired."

Here, the pronoun "it" should refer to "chicken", not "road." A well-functioning self-attention mechanism learns this relationship automatically by assigning a higher attention score from "it" to "chicken."

Key Idea

Each token is transformed into three learned vectors:

  • Query (Q): Represents what a token is "looking for" in the sequence.
  • Key (K): Represents what each token "offers" to others.
  • Value (V): The actual information carried by each token.

The attention weight between any two tokens is computed by comparing the Query of one token with the Key of another. These weights are used to compute a weighted sum of the Value vectors, resulting in a new representation that reflects both the token's identity and its contextual relationships.

The self-attention weight distribution α, used to compute the representation for the word "it" at layer k+1, assigns varying attention to words at layer k, with darker shades indicating stronger attention. Notably, the transformer focuses heavily on the tokens "chicken" and "road," which is logical since "it" could refer to either, making it beneficial for its representation to incorporate these earlier words' representations.

Summary of Benefits

  • Eliminates the need for recurrence or convolution
  • Supports parallel computation across sequences
  • Learns context-sensitive representations efficiently
  • Enhances performance on long and complex sequences

Mathematical Formulation: Query, Key, Value

Each input vector \(x_i \in \mathbb{R}^d\) is projected into three vectors using learned weights:

  • \(Q = X W^Q \in \mathbb{R}^{n \times d_k}\)
  • \(K = X W^K \in \mathbb{R}^{n \times d_k}\)
  • \(V = X W^V \in \mathbb{R}^{n \times d_v}\)

The attention score between token \(i\) and \(j\) is computed using the dot product of query and key vectors:

\[ \text{score}_{i,j} = \frac{Q_i \cdot K_j^T}{\sqrt{d_k}} \]

These scores are passed through a softmax function to obtain attention weights:

\[ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V \]

Attention matrix and weighted value computation.

Scale by $(\sqrt $)

Without scaling, the dot product values can grow large in magnitude, pushing softmax into regions with extremely small gradients. This makes training unstable. Scaling keeps the distribution more balanced.

Multi-Head Attention

While self-attention enables a model to compute context-aware representations of each token by attending to others in the sequence, it may be limited in expressiveness when using a single set of attention weights. Multi-head attention addresses this limitation by applying multiple parallel attention mechanisms, each with its own parameterization, allowing the model to capture a richer set of relationships.

Motivation

Different attention heads can specialize in learning different aspects of the sequence:

  • Some heads may learn syntactic relationships, such as subject–verb agreement.
  • Others may learn semantic or positional dependencies, such as referring expressions or word order.
  • Certain heads may focus on short-range dependencies, while others track long-distance connections.

This diversity allows the model to build robust and nuanced representations of text, far beyond what single-head attention can offer.

How Multi-Head Attention Works

Instead of computing a single set of attention weights, multi-head attention computes multiple independent self-attention operations (called heads) in parallel. Each head uses its own learned linear projections. This mechanism is a core innovation of the Transformer architecture, and is instrumental in its ability to model complex linguistic patterns. Each head uses its own set of weights: \(W^Q_i, W^K_i, W^V_i\). The outputs are concatenated and projected through a final linear layer:

\[ \text{MultiHead}(Q, K, V) = [\text{head}_1; \dots; \text{head}_h]W^O \]
\[ \text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h) W^O \]

The multi-head attention computation for input \(x_i\), producing output \(a_i\). A multi-head attention layer consists of \(A\) heads, each with its own key, query, and value weight matrices. The outputs from all heads are concatenated and projected to dimension \(d\), resulting in an output of the same size as the input.

Summary of Benefits

  • Parallel Processing: All heads compute attention simultaneously, allowing for efficient computation.
  • Representation Diversity: Each head learns different patterns and relationships within the sequence.
  • Expressive Power: Enables modeling of multiple linguistic phenomena concurrently, contributing significantly to the success of Transformer-based models in NLP.

Conclusion

In this lesson, you learned why attention mechanisms are necessary to overcome the bottlenecks in traditional Seq2Seq models. We explored how attention enables a decoder to selectively focus on relevant input tokens, and how self-attention generalizes this concept for intra-sequence modeling. Multi-head attention further enhances this ability by learning multiple types of relationships in parallel.
