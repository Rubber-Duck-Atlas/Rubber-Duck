Lesson: Cleaning Special Characters and Emojis

Introduction

Text data collected from various sources often contains unnecessary elements such as punctuation, URLs, emojis, and HTML/XML text. These elements can introduce noise into Natural Language Processing (NLP) tasks and impact the accuracy of machine learning models. Properly cleaning the text ensures better performance in text classification, sentiment analysis, and other NLP applications.

In this lesson, we will explore different techniques for removing special characters and emojis using regular expressions (re library) and NLP libraries.

Learning Outcomes

By the end of this lesson, you will be able to:

  1. Identify different types of unwanted characters in text data.
  2. Apply regular expressions to clean text efficiently.
  3. Utilize NLP libraries to handle URLs, punctuation, and emojis.
  4. Evaluate the impact of text cleaning on NLP applications.

Identifying Unwanted Characters

In raw text data, there are often unwanted characters that do not add value to the analysis and can negatively impact NLP models. These include:

  • Punctuation marks: !, ?, #, @, etc.
  • Special symbols: $, %, &, *, etc.
  • Digits (in some contexts): 0–9
  • Extra whitespace or non-printable characters: tabs, newlines, escape sequences
  • HTML tags or markup code: <div>, &nbsp;, etc.

Removing or handling these characters helps clean and normalize the text before tokenization or feature extraction.

Common Cleanup Tasks:

  • Removing punctuation and special symbols
  • Converting text to lowercase
  • Removing or replacing HTML tags
  • Replacing multiple spaces with a single space
  • Removing emojis or non-ASCII characters (if not relevant to the task)

Tip: Use regular expressions (regex) or built-in string functions to automate unwanted character filtering. Popular libraries like re in Python and tools in NLTK and spaCy can help with this.

Example:

text = "Visit our website at https://example.com! It's the best 😊 <p>Enjoy!</p>"

Before cleaning, the text contains unnecessary information. We will now explore techniques to remove such noise.

Removing Special Characters with Regular Expressions

In Natural Language Processing (NLP), special characters such as !, @, #, %, &, and punctuation marks often add noise to the data and should be removed—unless they carry meaningful context (e.g., @username in tweets).

Removing Punctuation

Python’s re module allows us to define patterns for removing unwanted text elements efficiently.

import re

text = "Hello, world! How's everything?"
clean_text = re.sub(r'[^\w\s]', '', text)  # Removes all punctuation
print(clean_text)

Output:

Hello world Hows everything

Removing URLs

text = "Check this out: https://example.com/news"
clean_text = re.sub(r'http\S+|www.\S+', '', text)
print(clean_text)

Output:

Check this out:

Removing HTML/XML Tags

text = "<p>Hello <b>world</b>!</p>"
clean_text = re.sub(r'<.*?>', '', text)
print(clean_text)

Output:
Hello world!

Handling Emojis and Symbols

Emojis and Unicode symbols often appear in social media, chat logs, and informal text. Depending on the NLP task, they can either be:

  • Removed to reduce noise (e.g., for formal text analysis), or
  • Converted into text descriptions to preserve emotional or semantic meaning (e.g., for sentiment analysis).

Two helpful Python libraries for this are:

  • emoji: For detecting and converting emojis to text.
  • unicodedata: For handling general Unicode characters and their categories.

Removing Emojis

import emoji

text = "Python is amazing! 🙂👍"
clean_text = emoji.replace_emoji(text, replace='')
print(clean_text)

Output:

Python is amazing!

Converting Emojis to Text Descriptions

text = "Python is amazing! 🙂👍"
converted_text = emoji.demojize(text)
print(converted_text)

Output:

Python is amazing! :slightly_smiling_face: :thumbs_up:

Removing Non-Alphanumeric Symbols

import unicodedata

text = "Hello ☀️! It's a beautiful day."
clean_text = ''.join(c for c in text if unicodedata.category(c)[0] != 'S')
print(clean_text)

Output:

Hello ! Its a beautiful day.

Combining All Cleaning Steps

We can combine these techniques into a single function for efficient text preprocessing:

def clean_text(text):
    text = re.sub(r'http\S+|www.\S+', '', text)  # Remove URLs
    text = re.sub(r'<.*?>', '', text)  # Remove HTML/XML tags
    text = re.sub(r'[^\w\s]', '', text)  # Remove punctuation
    text = emoji.replace_emoji(text, replace='')  # Remove emojis
    return text

text = "Visit https://example.com! Amazing offers 🔥 <p>Don't miss out!</p>"
cleaned_text = clean_text(text)
print(cleaned_text)

Output:

Visit Amazing offers Dont miss out
