Lesson: Basics of Recurrent Neural Networks

Introduction

Many Natural Language Processing tasks, such as language modeling, text classification, and machine translation, require processing sequences of words or characters. Traditional feedforward networks and embeddings (as explored in Week 2 and earlier in Week 3) treat input words independently, failing to capture temporal dependencies and contextual flow. Recurrent Neural Networks (RNNs) are specifically designed to offer a solution by incorporating a mechanism to process data sequentially, maintaining a memory of previous inputs to inform future predictions.

This lesson explores how RNNs address the challenge of sequential data processing and examines the foundational processes of forward and backward propagation that enable their functionality, setting the stage for understanding their applications in tasks like language modeling and sentiment analysis.

Learning Outcomes

By the end of this lesson, you will be able to:

  1. Explain how RNNs process sequential data using a hidden state to capture temporal dependencies.
  2. Describe the forward propagation process in RNNs, including the role of recurrent connections.
  3. Understand the concept of backpropagation through time (BPTT) and its application in training RNNs.

Processing Sequential Data with RNNs

RNNs are uniquely designed to handle sequential data, such as sentences or time series, by processing one element at a time while preserving information from prior elements. Unlike feedforward networks, which treat inputs independently or within a static window, RNNs maintain a hidden state that acts as a memory, updated at each time step to reflect the cumulative context of the sequence.

Consider a sentence like:

I like cats.

In a feedforward network, each word might be processed independently or within a fixed context, missing the broader sequential relationship. RNNs, however, process this sentence incrementally: starting with "I" then "like," and finally "cats." with each step influencing the next through the hidden state. This hidden state, denoted as \(\mathbf{h}_t\) at time \(t\), encapsulates information from all previous inputs, theoretically allowing the network to remember details from the sequence's beginning without a fixed-length constraint.

The architecture of an RNN includes a recurrent connection, where the hidden layer at time \(t\) receives input not only from the current input \(\mathbf{x}_ t\) but also from the hidden layer at the previous time step, \(\mathbf{h}_{t-1}\). This loop enables the network to maintain a form of memory, making it adept at tasks where context matters, such as predicting the next word in a sentence.

Forward Propagation in RNNs

Forward propagation in RNNs is the process by which the network computes outputs for a given sequence, step by step, leveraging both current inputs and past context. This process mirrors feedforward networks but incorporates the recurrent connection, making it sequential rather than simultaneous.

The mathematical formulation is as follows:

Input Vector: \(\mathbf{x}_t\), the input at time \(t\), (e.g., a one-hot encoded word).

Hidden State: \(\mathbf{h}_t\),

computed as:

\[ \mathbf{h}_ t = g(\mathbf{U} \mathbf{h}_ {t-1} + \mathbf{W} \mathbf{x}_ t) \]

where:

  • \(\mathbf{U}\) is the weight matrix for the recurrent connection from \(\mathbf{h}_{t-1}\)
  • \(\mathbf{W}\) is the weight matrix for the input \(\mathbf{x}_t\)
  • \(g\) is a non-linear activation function (e.g., tanh or ReLU)

Output Vector:

\[ \mathbf{y}_t = f(\mathbf{V} \mathbf{h}_t) \]

where \(\mathbf{V}\) is the weight matrix to the output layer, and \(\(f\)) is typically a softmax for probability distributions.

To see this, consider the folowing figure which clarifies the nature of the recurrence and how it factors into the computation at the hidden layer:

Simple recurrent neural network illustrated as a feedforward network.

The most significant change lies in the new set of weights, U, that connect the hidden layer from the previous time step to the current hidden layer. These weights determine how the network makes use of past context in calculating the output for the current input. As with the other weights in the network, these connections are trained via backpropagation.

For the initial time step \((t=1\)), \(\mathbf{h}_0\) is often set to a zero vector since no prior context exists. Let’s apply this to our example, "I like cats":

Time \(t=1\): Input \(\mathbf{x}_1\) represents "I." The hidden state becomes:

\[ \mathbf{h}_1 = g(\mathbf{U} \mathbf{h}_0 + \mathbf{W} \mathbf{x}_1) \]

and the output:

\[ \mathbf{y}_1 = f(\mathbf{V} \mathbf{h}_1) \]

predicts the likelihood of the next word (e.g., "like").

Time \(t=2\): Input \(\text{x}_2\) is "like." Using \(\text{h}_1\), the network computes \(\mathbf{h}_1\), the network computes:

\[ \mathbf{h}_2 = g(\mathbf{U} \mathbf{h}_1 + \mathbf{W} \mathbf{x}_2) \]

and predicts:

\[ \mathbf{y}_2 = f(\mathbf{V} \mathbf{h}_2) \]

Time \(t=3\): Input \(\text{x}_3\) is "cats," updating \(\text{h}_3\) and producing \(\text{y}_3\).

Backward Propagation Through Time (BPTT)

Training RNNs requires adjusting the weights \(\text{W}\), \(\text{U}\), \(\mathbf{V}\) to minimize prediction errors, using a loss function like cross-entropy. Since RNNs process sequences, standard backpropagation is extended to Backpropagation Through Time (BPTT), accounting for temporal dependencies.

In BPTT, the network is conceptually "unrolled" over time, transforming it into a feedforward-like structure where each time step is a layer. This unrolling reveals that weights are shared across time steps, and the total loss is the sum of losses at each step. For a sequence of length \(\(T\)), the loss is:

\(L = \sum_{t=1}^T L_t\)

where \(L_t\) is the loss at time \(t\). The gradient of \(L\) with respect to a weight (e.g., \(\text{U}\) is the sum of gradients across all time steps, computed by propagating the error backward from the end of the sequence to the beginning.

A simple recurrent neural network shown unrolled in time.

This figure depicts the unrolled network, illustrating how layers are replicated for each time step while weights remain shared, facilitating gradient computation via BPTT.

For long sequences, unrolling the entire sequence can be resource-intensive, leading to truncated BPTT, where the sequence is processed in fixed-length segments. Modern frameworks like TensorFlow automate BPTT, simplifying implementation by handling the unrolling and gradient calculations internally when the recurrent structure is defined.

Implementation Example

A simple RNN can be implemented using PyTorch:

import torch
import torch.nn as nn

rnn = nn.RNN(input_size=10, hidden_size=20, num_layers=1, batch_first=True)
inputs = torch.randn(32, 5, 10)  # (batch, sequence, input_size)
h0 = torch.zeros(1, 32, 20)

output, hn = rnn(inputs, h0)
print(output.shape)  # torch.Size([32, 5, 20])

Output:

torch.Size([32, 5, 20])

This output indicates that for each of the 5 time steps, the RNN produces a hidden state vector of size 20 for each of the 32 sequences.

Conclusion

This lesson has introduced the core principles of Recurrent Neural Networks, emphasizing their ability to process sequential data through a hidden state that captures temporal context, a capability that distinguishes them from traditional neural networks. We explored forward propagation, detailing how RNNs compute outputs incrementally using recurrent connections, and backward propagation through time, which adapts backpropagation to train these networks effectively. These concepts form the foundation for applying RNNs to real-world tasks, such as predicting the next word in a sentence or analyzing sentiment in text, providing you with the tools to understand and leverage their sequential processing power.

Understanding these foundational concepts is essential before exploring more advanced RNN architectures like LSTMs and GRUs in the upcoming lessons.
