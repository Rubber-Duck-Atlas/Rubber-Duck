Lens Distortion Correction

Lens distortion refers to the geometric misplacement of image information from its ideal shape, which occurs due to the inherent optical properties of camera lenses. This correction is essential for accurately representing objects and enhancing the reliability of computer vision applications, such as facial recognition.

Distortions happen because when a light ray passes through the curved surface of a lens, it experiences varying degrees of refraction depending on where it intersects with the curvature. As a result, certain areas of the image, particularly at the edges, may become unevenly magnified or compressed.

The most common types are:

  • Barrel Distortion: Causes straight lines to bulge outward, like a fisheye effect.
  • Pincushion Distortion: Causes straight lines to bend inward, giving an unnatural, stretched look.

How Does Lens Distortion Correction Work?

LDC (Lens Distortion Correction) helps fix the bending or warping in images caused by camera lenses. It does this by using a special lens profile designed for a specific lens.

How is a Lens Profile Created?

  • The lens is tested using known patterns (like calibration charts) to see how it distorts the image.
  • Different settings, such as sensor size, resolution, and focal length, are adjusted until the distortion is corrected.
  • Once the corrections look right, these settings are saved as a lens profile for future use.

What If the Lens is Unknown? If the lens distortion isn’t pre-tested, generic LDC algorithms can still help reduce distortion, but they may not be as precise as a custom profile.

In the context of security camera systems, correcting lens distortion plays a crucial role in enhancing overall performance and ensuring consistent results. By dewarping video feeds, it not only facilitates easier human monitoring but also improves the accuracy of detection systems that utilize Computer Vision (CV).

Correcting Lens Distortion with OpenCV

Modern algorithms allow us to correct these distortions by modeling the camera’s intrinsic parameters. Let’s apply a distortion correction using OpenCV.

First, we need to obtain camera calibration parameters (intrinsic matrix and distortion coefficients), which are typically computed using a chessboard calibration technique. Here’s a simplified approach assuming we already have these values:

import cv2
import numpy as np
from google.colab.patches import cv2_imshow 

# Load the distorted image from URL
image = cv2.imread("distortion.jpg")  # Download the image and save it locally first

# Example camera matrix and distortion coefficients (for demonstration purposes)
camera_matrix = np.array([[800, 0, 320], 
                          [0, 800, 240], 
                          [0, 0, 1]], dtype=np.float32)
dist_coeffs = np.array([-0.3, 0.1, 0, 0, 0], dtype=np.float32)

# Correct distortion
h, w = image.shape[:2]
new_camera_matrix, roi = cv2.getOptimalNewCameraMatrix(camera_matrix, dist_coeffs, (w,h), 1, (w,h))
undistorted_image = cv2.undistort(image, camera_matrix, dist_coeffs, None, new_camera_matrix)

# Display results
cv2_imshow(image)
cv2_imshow(undistorted_image)
cv2.waitKey(0)
cv2.destroyAllWindows()

Histogram Equalization and Contrast Normalization

In many images—especially those captured in low-light or uneven lighting—important details can be hidden in overly dark or bright regions. To make these features more visible and improve the overall visual quality, we use techniques like histogram equalization and contrast normalization.

These methods enhance the image by redistributing pixel intensities or scaling contrast levels, making edges, textures, and objects easier to detect and analyze. Proper contrast adjustment can dramatically improve feature visibility and model accuracy for both human viewing and computer vision tasks.

Why Is Contrast Enhancement Important?

Imagine looking at an old newspaper where the ink has faded, making it difficult to read. In computer vision, poor contrast affects feature extraction, edge detection, and classification accuracy in machine learning models. Histogram equalization helps by redistributing brightness values to improve visibility.

Histogram equalization: It is an image processing technique used to enhance the contrast or adjust the brightness values of an image. This method equalizes the pixel intensities of the image, making the distribution of color and brightness more balanced.

The process of histogram equalization involves the following steps:

  1. Histogram Creation: A histogram is generated based on the pixel intensities of the image.
  2. Cumulative Distribution Function (CDF) Calculation: The cumulative sum of each bin in the histogram is computed, representing the overall pixel intensity distribution of the image.
  3. Normalization: The cumulative distribution function is normalized, ensuring that values fall within a range of 0 to 255.
  4. Applying the Transformation Function: Each pixel in the original image is transformed by considering the normalized CDF, resulting in a new value.

Histogram equalization is used for applications such as enhancing image details, making the image more vibrant, or feature extraction. However, it should be noted that it may overly emphasize certain features or increase noise in some cases.

Example Code for Histogram Equalization in OpenCV:

# load grayscale image
image = cv2.imread('dog.jpg', cv2.IMREAD_GRAYSCALE)

# Apply histogram equalization
equalized = cv2.equalizeHist(image)

# Create a figure with subplots to compare the images
plt.figure(figsize=(30, 10))

# Show equalized image
plt.subplot(1, 3, 1)
plt.imshow(equalized, cmap='gray', vmin=0, vmax=255)
plt.title('Equalized Image')

# Compare original and equalized histograms
plt.subplot(1, 3, 2)
plt.hist(image.flatten(), 256, [0, 256])
plt.title('Original Histogram')
plt.subplot(1, 3, 3)
plt.hist(equalized.flatten(), 256, [0, 256])
plt.title('Equalized Histogram')
plt.show()
plt.show()
