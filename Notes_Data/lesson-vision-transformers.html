Lesson: Vision Transformers

Introduction

Picture a detective unraveling a mystery in a vast mansion. A traditional detective, like a Convolutional Neural Network (CNN), uses a small flashlight to inspect each room, piecing together local clues like edges or textures. But what if the detective could capture a panoramic snapshot, instantly connecting clues across the entire scene—like a cat’s eyes in one corner to its whiskers in another? That’s the power of Vision Transformers (ViTs). By treating an image like a sentence, breaking it into puzzle pieces (patches), and using self-attention to link them globally, ViTs revolutionize tasks like classifying a cat in a photo, detecting objects in videos, or segmenting medical images. This lesson walks you through how ViTs process a cat image, why they sometimes outshine CNNs, and how you can use them to become a master detective in vision tasks.

Learning Objectives

By the end of this lesson, you will be able to:

  1. Explain the self-attention mechanism and how ViTs process image patches instead of convolutions to capture global relationships in images.
  2. Compare ViTs with CNNs in terms of efficiency, interpretability, and performance across vision tasks like classification, detection, and segmentation.
  3. Apply a pretrained ViT model to classify an image and visualize its attention to understand how it makes decisions.

Component 1: Image to Sequence Conversion – Turning a Cat Image into Words

Imagine a 224x224 photo of a cat—its eyes sparkling, whiskers twitching. Instead of scanning it pixel by pixel with a CNN’s small filter, image to sequence conversion chops the image into 196 square patches (16x16 pixels), like breaking a sentence into words. Each patch is flattened into a 768-number vector (3 channels × 16 × 16), transformed into a compact embedding via a linear layer, and tagged with a positional encoding to track its place. A special [CLS] token is added to summarize the cat’s features, forming a sequence of 197 “words” (196 patches + [CLS]). This replaces CNNs’ local convolutions, enabling global analysis.

Since the Transformer treats patches like words in a sentence, and word order matters (e.g., "cat chases dog" vs. "dog chases cat"), we need to tell the model where each patch is located. Positional encodings are like unique labels or coordinates added to each patch, helping the model know that the eye patch is near the top-left while the whisker patch is to the right. These encodings can be fixed patterns (like waves) or learned during training.

Design Implications of Image-to-Sequence Conversion

Understanding how Vision Transformers (ViTs) process images differently from Convolutional Neural Networks (CNNs) is key to appreciating their unique strengths and the design trade-offs involved.

  • Global Processing with PatchesUnlike CNNs that rely on small filters (e.g., 3×3) to learn local patterns, ViTs operate on image patches, enabling them to capture global context from the start. This means a ViT can associate the cat’s eyes with its tail in a single attention step—something CNNs achieve only after multiple stacked layers.
  • Input Normalization & PreprocessingImages are resized to 224×224 pixels and pixel values are normalized to [-1, 1]. This standardization ensures compatibility with pretrained ViTs (e.g., trained on ImageNet) and stabilizes training across varying inputs.
  • Patch Size Trade-Offs
    • Smaller patches (e.g., 16×16) create more tokens (196 per image), allowing ViTs to capture fine-grained details (like whiskers), but increase computational load.
    • Larger patches (e.g., 32×32) reduce the number of tokens (49 per image), improving efficiency—but potentially missing subtle features.

These design choices, especially patching strategy, affect not only accuracy and interpretability but also scalability and deployment cost. ViTs are most effective when tuned to the right patch size and input conditions for the task at hand.

Visualizing Patch Embedding

Imagine splitting an image into square patches, each assigned a unique color or number based on its position. For example, the top row patches might be numbered 1 to 14, the second row from 15 to 28, and so on much like reading pixels in blocks from left to right, top to bottom. This positional labeling is crucial because, unlike CNNs, ViTs lack inherent spatial awareness. To help the model understand where each patch comes from, a positional encoding is added to each patch embedding. This allows the transformer to learn both what is in a patch and where it belongs in the image.

Think of it as assigning GPS coordinates to image chunks—the transformer doesn’t just know what it sees, but also where it’s seeing it.

Code Example & Trade-offs

import torch  
from torchvision.transforms import Compose, Resize, Normalize, ToTensor  
from PIL import Image  
import matplotlib.pyplot as plt  

# Load image (ensure 'cat.jpg' is in your directory)  
cat_image = Image.open('cat.jpg').convert("RGB")  # Ensure RGB  

# Preprocess and create patches  
def preprocess_and_patch(image, patch_size=16):  
    transform = Compose([Resize((224, 224)), ToTensor(), Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))])  
    image = transform(image).unsqueeze(0)  # Shape: (1, 3, 224, 224)  
    patches = image.unfold(2, patch_size, patch_size).unfold(3, patch_size, patch_size)  
    patches = patches.reshape(-1, 3 * patch_size * patch_size)  # Shape: (196, 768)  
    return patches  

patches = preprocess_and_patch(cat_image, patch_size=16)

Output: The 224x224 cat image becomes 196 patches (14×14 grid), each a 768-dim vector. Larger patches (32x32) yield 49 patches, reducing computation but losing detail.

Component 2: Transformer Processing – Linking the Cat’s Features

Now that the cat image is a sequence of 197 pieces (196 patches + [CLS] token), Transformer processing acts like the detective’s superpower: it looks at all pieces at once, figuring out how they connect—like linking the cat’s eyes to its whiskers. Unlike CNNs, which check small areas step-by-step, the Transformer uses self-attention to see the whole picture. With 12 layers (in ViT-B/16), it refines the cat’s features, ensuring every piece contributes to the final understanding.

Self-Attention Simplified

Self-attention allows each image patch to ask: “Which other patches should I focus on to understand the whole image?” For example, a patch containing the cat’s eye might attend to the whisker patch to strengthen its belief that the image is indeed a cat. The model calculates a connection score between every pair of patches, determining how much attention each one deserves. This global perspective is what gives Vision Transformers (ViTs) their edge over CNNs, which rely on localized filters.

Key Impacts of Self-Attention

  • Multiple Attention HeadsThe Transformer uses multiple heads (e.g., 12) in parallel. Each head captures a different relationship, one might track shape (e.g., eyes), another texture (e.g., fur), helping the model form a richer understanding.
  • Layer-by-Layer RefinementAs attention flows through layers (typically 12 in ViT-Base), each stage refines the image representation, like a detective adding details to a suspect sketch with every clue.
  • Computational CostSelf-attention compares every patch with every other patch, making it quadratic in complexity. While this enables holistic vision, it also means ViTs can be slower and more memory-intensive than CNNs, especially on large images.

Self-Attention Calculation Walkthrough (Two-Patch Example)

Let’s simplify with two patches: one with the cat’s eye and one with its whisker. Each patch becomes three vectors:

  • Query (Q): What I’m looking for (e.g., “I need whisker-like features”).
  • Key (K): What I have (e.g., “I have whisker features”).
  • Value (V): What I’ll share (e.g., whisker details).

Example:

  • Eye Patch: \(Q = [1, 0], K = [0, 1], V = [2, 3]\)
  • Whisker Patch: \(Q = [0, 1], K = [1, 0], V = [4, 5]\)
  1. Connection score (Eye to Whisker): \(Q_{eye} • K_{whisker} = [1, 0] • [1, 0] = 1 (strong match)\)
  2. Connection score (Eye to itself): \(Q_{eye} • K_{eye} = [1, 0] • [0, 1] = 0 (weak match)\)
  3. Attention weights: \(Softmax([0, 1]) ≈ [0.27, 0.73]\)
  4. New representation for Eye: \(0.27 × V_{eye} + 0.73 × V_{whisker} = 0.27 × [2, 3] + 0.73 × [4, 5] = [3.46, 4.46]\)

This shows the eye patch incorporating whisker info to better understand the cat.

Code Example & Trade-offs

import torch  
import torch.nn as nn  

# Simplified Transformer layer  
class TransformerLayer(nn.Module):  
    def __init__(self, piece_size=768, num_connectors=12):  
        super().__init__()  
        self.connector = nn.MultiheadAttention(piece_size, num_connectors, batch_first=True)  
        self.thinker = nn.Sequential(nn.Linear(piece_size, piece_size * 4), nn.GELU(), nn.Linear(piece_size * 4, piece_size))  
        self.adjuster1 = nn.LayerNorm(piece_size)  
        self.adjuster2 = nn.LayerNorm(piece_size)  

    def forward(self, pieces):  
        connected_pieces, connection_scores = self.connector(pieces, pieces, pieces, need_weights=True)  
        pieces = self.adjuster1(pieces + connected_pieces)  
        thought_pieces = self.thinker(pieces)  
        pieces = self.adjuster2(pieces + thought_pieces)  
        return pieces, connection_scores  

layer = TransformerLayer()  
cat_pieces = torch.rand(1, 197, 768)  
output, connection_scores = layer(cat_pieces)

Output: A 197×197 table of connection scores links features globally. ViT-B/16 uses ~8B FLOPs (Floating Point Operations Per Second, is a measure of a computer's or processor's performance, specifically how many calculations involving floating-point numbers it can perform each second), more than ResNet-50’s ~4B, due to this global approach.

Component 3: From Features to Predictions – Identifying the Cat

After connecting the cat’s 197 pieces, ViTs deliver a verdict: “This is a cat!” From features to predictions is like the detective writing a final report, using the [CLS] token’s summary to pick one of 1000 ImageNet labels. The [CLS] token, a 768-number list, aggregates the cat’s features (eyes, whiskers). A linear layer acts like a scoring system, matching this summary to labels and picking the highest score (e.g., “cat”).

Output Interpretation and Design Significance

  • [CLS] TokenServes as the global summary, collecting information from all patches across all layers.
  • Linear LayerA lightweight classifier that transforms the [CLS] embedding into label probabilities.
  • CNNs vs. ViTsWhile CNNs aggregate spatial features via pooling and dense layers, ViTs rely on the [CLS] token’s attention-based summary—offering more global flexibility and learned contextual relevance.

Visual Description: Picture the [CLS] token as a glowing orb absorbing info from patch orbs. It brightens with each layer, then sends its light to a decision box sorting it into label bins (e.g., “cat”).

Architectural Comparison: Vision Transformers vs. CNNs

Vision Transformers (ViTs) and Convolutional Neural Networks (CNNs) differ fundamentally in how they process visual data. This comparison highlights trade-offs in computational cost, accuracy, and data requirements across architectures.

Benchmark Comparison

Model Patch Size # of Patches FLOPs ImageNet Accuracy
ViT-B/16 16×16 196 ~8B 88.5%
ViT-B/32 32×32 49 ~2B 85.0%
ResNet-50 N/A N/A ~4B 76.1%
  • Interpretation: Smaller patches (e.g., 16×16) yield higher accuracy by capturing finer details, but they increase the number of tokens—and thus computation. ResNet-50, while more efficient, offers lower top-1 accuracy.

Key Insights

  • EfficiencyViTs scale computation quadratically with the number of patches (i.e., smaller patch sizes mean much higher FLOPs). CNNs, by contrast, grow linearly, making them more computationally stable on high-resolution images.
  • InterpretabilityViTs model global relationships early through self-attention, offering intuitive attention maps. CNNs emphasize local feature extraction, making them easier to debug in low-data regimes but limited in global understanding.
  • Performance Context
    • ViTs perform best with large datasets and extensive pretraining.
    • CNNs generalize better on small or medium datasets with limited compute.

This comparison emphasizes that no architecture is universally better—ViTs unlock new capabilities in large-scale vision tasks, while CNNs remain practical and robust in resource-constrained settings.

Hands-On Activity

from transformers import ViTImageProcessor, ViTForImageClassification  
from PIL import Image  
import torch  
import matplotlib.pyplot as plt  

# Visualize patches  
def visualize_patches(image, patch_size=16):  
    transform = Compose([Resize((224, 224)), ToTensor()])  
    image = transform(image).unsqueeze(0)  
    patches = image.unfold(2, patch_size, patch_size).unfold(3, patch_size, patch_size)  
    patches = patches.reshape(-1, 3, patch_size, patch_size)  
    grid_size = 14 if patch_size == 16 else 7  
    fig, axs = plt.subplots(grid_size, grid_size, figsize=(10, 10))  
    for i in range(grid_size):  
        for j in range(grid_size):  
            patch = patches[i * grid_size + j].permute(1, 2, 0).numpy()  
            axs[i, j].imshow(patch)  
            axs[i, j].axis('off')  
    plt.show()  

cat_image = Image.open('cat.jpg').convert('RGB')  
visualize_patches(cat_image, patch_size=16)  # Try patch_size=32  

# Classify image  
processor = ViTImageProcessor.from_pretrained('google/vit-base-patch16-224')  
model = ViTForImageClassification.from_pretrained('google/vit-base-patch16-224')  
inputs = processor(images=cat_image, return_tensors="pt")  
outputs = model(**inputs)  
label = model.config.id2label[outputs.logits.argmax(-1).item()]  
print(f"Predicted label: {label}")
